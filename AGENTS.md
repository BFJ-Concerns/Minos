# Pump-19

Agent-native code verification — and the agent tooling built on the same
framework. Early stage; no code yet.

A harness of *independent* oracles (deterministic intent-derived tests +
cross-engine judgement) giving an automated author the most assurance it can get
about code *ahead of execution*, since no human routinely exercises the result.
Designed to stand alone on any agent-authored repo; the `Widget` server is its
first consumer. The agent-tooling side (the Foundry) shares the same framework.

Planning, intent, and design live in the sibling annexe `../Pump-19-Annexe` — its
`README.md` is the commission (the project's contract). Start there; this repo is
code-only and currently empty.
